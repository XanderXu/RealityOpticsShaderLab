# 新增效果的复查与修复

本轮复查覆盖效果分组、12 个新增效果、材质模板、光谱 LUT 与验证脚本。保留既有 28 项效果和双模型预览。

## 确认的问题

| 问题 | 证据与影响 | 修复 |
|---|---|---|
| 背面光被当作正面光 | 原 `abs(N·L)` 在 N·L=-1 时返回 1；日光石的闪点甚至没有乘入射权重 | 先将双面薄片法线朝向观察者，再取 max(N·L,0)；猫眼、星光、月光石、拉长石、日光石和逆反射都正确处理光线所在半球 |
| 日光石密度改变朝向分布 | 同一个随机值既决定包裹体是否存在，又决定片层法线 X 分量；提高阈值会偏选 +X 朝向 | 片层朝向与包裹体占用使用独立随机值；只增加一个廉价 cell hash，不增加纹理 |
| 多色性第三晶轴不易观察，球体缺少曲率线索 | 原控制和默认动画均绕 Y 轴；材质输出只依赖视线，球体容易看成平面圆片 | 增加 0–90° 晶轴倾角；保持三个正交轴；为显示增加中性的明暗层次，RGB 吸收模型保持不变 |
| 新增膜类重复采样，二向色重复光谱计算 | 四种膜每像素使用两次 image 采样；二向色对同一堆栈分别计算 R 和 T | 单次采样保留未截断的线性 RGB(R)，由 RGB(white)−RGB(R) 得到透射，再各自做显示色域截断 |
| 参数最小值检查会关闭被检查的效果 | 原 MIN 阶段同时把 Intensity 设为 0，光学分支被中性底色遮盖 | MIN/MAX 检查固定 Intensity=1；强度本身的 0/1/2 仍由静态回归验证；增加名义参数下的反射/透射和第三晶轴截图 |
| 搜索首尾空格导致无结果 | 直接使用未处理的文本进行匹配 | 匹配时去掉首尾空白，不改变用户正在编辑的文本 |

体色、内部散射和包裹体仍是已标注的实时外观近似。新增显示阴影不代表求解了体积光路；本轮也不把变石的 RGB 端点示意改称实测光谱模型。

## 单 LUT 优化的适用条件

只有无吸收的二向色膜使用能量关系 T(λ)=1−R(λ)。线性光谱积分允许在 RGB 空间作同样的减法，但必须在色域截断之前做。RGB 中的负分量表示超出线性 sRGB 色域，不表示负光谱反射率。

- 二向色 LUT 用 RGBA16F 保留带符号的 RGB 反射数据；普通膜和原有 LUT 继续保持原格式语义。
- 白点从现有 CIE/D65 积分取得，不硬编码假定恰为 (1,1,1)。
- 反射和透射各自在 ShaderGraph 中截断到非负显示颜色，再做通道混合、增益和底色混合。
- 钛基底有吸收，不能把 1−R 当作真实透射；应用仍只为二向色开放透射控制。
- 独立的透射 CPU/GPU 参考仍保留在验证程序中，正常运行不加载这张参考 LUT。

二向色正常路径从两张纹理、两次光谱积分减为一张，节省 **512 KiB** 常驻像素数据；四种新增膜的图从两次采样减为一次。固定 LUT 常规依赖数从 10 降为 9，加上四项 IOR 缓存，上界从 14 张/6.76 MiB 降为 **13 张/6.26 MiB**。22 个运行时模板保持不变。上述是分配与计算次数变化，不宣称真机帧率提升。

## 验证

- 41 项 CPU 测试通过。新增测试直接比较独立 R/T 光谱积分，并验证色域截断顺序。
- 24 份图、984 个节点、107 个参数默认值通过 MaterialX 官方签名及算术回归；涵盖背面入射、双面朝向、密度/朝向独立性、晶轴可达性与未截断颜色互补。
- 13 种完整尺寸 LUT 和 257×129 非整除纹理通过 GPU/CPU 对照；单 LUT 重建透射的最大绝对误差约 **0.000501**、RMSE **0.000157**，仍满足原容差（0.003 / 0.0002）。
- 当前构建与模拟器记录位于 `artifacts/review-effects-audit`；日光石最后一处随机分布修正另行保存到 `artifacts/review-sunstone-audit`。反射/透射与第三晶轴对比采用名义增益，避免极值过曝掩盖区别。

最终 Debug / Release 构建通过。全量 28 项默认与可见 MIN/MAX 运行验收通过，共 31 张截图；日光石最后的随机分布修正单独复验通过。28 项 × 两组模型 × 九种底色 × 三档占比的预览绑定回归通过。

缓存实测保持启动 1 个模板/1 张 LUT（本次模拟器资源就绪约 1.21 秒）；IOR 压力测试后 22 个模板/13 张纹理/6,561,792 字节像素数据，280 次缓存请求零重建。该时间不代表首帧、清空系统缓存后的冷启动或真机 FPS。参见 [缓存日志](../artifacts/review-cache-audit/runtime.log)、[预览日志](../artifacts/review-preview-audit/runtime.log)。
