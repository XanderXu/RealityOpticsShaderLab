# 视角相关效果扩展

新增 7 项，效果库共 35 项、9 个分组。全部接入原有参数、基础色、双模型和懒加载路径；没有屏幕颜色读取或全屏后处理。

| 效果 | 实现 | 边界 |
|---|---|---|
| 宝石火彩 | 程序三角切面法线、三波段折射、一次内部反射、6 次环境采样 | 使用固定环境与近似光路，不追踪真实宝石内部几何；色散强度允许夸张展示 |
| 吸收玻璃 | Snell 入射方向、有限平板光程、RGB Beer–Lambert 吸收、非偏振介质 Fresnel 反射，2 次环境采样 | 所有预览网格使用由厚度参数定义的平板光程模型，非真实透视背景 |
| 柱镜变图 | Compute 生成 2×2 四视图图集，观察斜率选择相邻两幅图像，2 次采样 | 图案为程序纹理；柱镜条带采用选图近似 |
| 彩色莫尔纹 | 弯曲双层条纹、角度视差、频率与旋角差；解析保留差频 | 三色为显示映射，不是光谱干涉；不依赖亚像素采样混叠，无 LUT |
| 视差星云 | 2×2 四层彩云／星点图集，固定深度的后向前合成，4 次采样 | 有界视差与亮度遮挡，不是完整体积积分；掠视时偏移限制以避免发散 |
| 雨虹与双虹 | 色散水滴的驻定偏向角，81 波长积分，1 次角度 LUT 采样 | 主副虹采用高斯展宽和近似相对强度；视点与光源控制虹带，纯模型自转不必改变虹带 |
| 大气霞光 | 球壳解析视线长度、Rayleigh 光谱单次散射、太阳方向与昼夜衰减，1 次 LUT 采样 | 在表面显示球壳外观，没有外部体积；太阳路径和日落为近似，平面不产生球形轮廓 |

## 资源与性能

新增 5 份不可变纹理：环境 256×128，视图／星云图集各 512×512，雨虹 1024×64，大气 256×256。均由已有 Compute 管线写入 RGBA16F LowLevelTexture，像素负载合计 5.25 MiB；Compute 管线不可用时仍走 CPU 计算与异步上传。

- 宝石与玻璃共用环境纹理。每项仅首次访问时生成依赖，参数更新不重建纹理。
- 35 项共 29 个材质模板；两个预览模型共享所选效果的参数和纹理。
- 光谱积分与视线计算保留 float32，权重及纹理仍用 16-bit。81 组雨虹偏向角／Rayleigh 系数只计算一次，共享 1,296 字节常量缓冲；CPU 回退直接累加 RGB，省去每个像素的临时光谱数组。
- 图集每个分块均内缩半个 texel；钳制坐标避免相邻视图串色，越界层渐隐以消除斜视时边缘拉伸。
- 莫尔纹直接计算差频，省去高频叠层采样；星云使用固定四层，共用表面坐标，开销不随深度参数增长。柱镜两次采样与原四次采样在允许的过渡宽度内等价。
- 资源像素字节数不代表 RealityKit 的内部显存、编译缓存或真机峰值。

## 生成与验证

`Scripts/generate_extended_materials.py` 导入 `Scripts/spatial_effects.py`，生成对应 USDA 和 Swift 控件。不要只修改生成文件。

验证内容：官方 MaterialX 节点端口、所有控制的默认／上下限、前侧／背侧有限性、吸收随厚度变化、莫尔纹视差、四视图索引与图集边界；CPU 的主副虹角度及反向色序、大气昼夜响应；Metal／CPU 全尺寸逐 texel 对照。

模拟器入口：

```bash
python3 Scripts/capture_shader_audit.py --spatial --output artifacts/spatial-review-audit
python3 Scripts/capture_shader_audit.py --preview --output artifacts/spatial-preview-audit
python3 Scripts/capture_shader_audit.py --performance --output artifacts/spatial-review-cache
```

`--spatial` 检查七项的默认／最小／最大参数，保存正面、斜视、背面及雨虹／大气光源比较共 23 张截图。它通过应用内部调试入口设置状态，不替代真机交互、帧时间或功耗测量。

## 复查修复

- 玻璃在折射率为 1 时不再产生错误的掠射反射；复用折射余弦计算介质 Fresnel，折射根式采用避免近掠射相消的形式。
- 莫尔纹第二层改为绕纹理中心旋转，消除旋角附带的平移。
- 增加折射向量长度、折射率匹配、莫尔纹旋转中心及 903 组柱镜混合等价检查；优化后的 CPU 光谱表与独立公式对照。
